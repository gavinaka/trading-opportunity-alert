# 停止条件

以下任一条件出现，必须停止，不发送正式 Taker 预警：

- TradingView payload 缺少品种、周期、信号、方向或价格。
- 早盘关键位上下文缺少计划ID、关键位、区间、失效参考或触发场景，且用户没有在当前对话里补齐。
- 信号不属于：突破确认、假突破、假跌破、流动性猎杀反转、2B反转。
- 价格不是有效正数。
- 候选事件重复。
- 关键位、前高、前低或区间边界不明确。
- 2B 周期低于 15m。
- 2B 没有完成“越过关键位失败并收回”的右侧确认。
- 流动性猎杀只有插针，没有结构收回或关键位确认。
- 入场、失效、止损、TP1、TP2、取消、风控、理由任一字段缺失。
- 止损过宽、滑点风险不可控或盈亏比不足。
- 置信度低于配置阈值。
- Telegram API 未配置且不是 dry-run。
- `Trading-System` 需要写入才能继续。
